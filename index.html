Akiro’s Allround Mod

A Hypixel SkyBlock mod that tracks your auction flip profit automatically and shows it right in the game.Мод для Hypixel SkyBlock, который сам считает прибыль с аукционных флипов и показывает её прямо в игре.

Minecraft 26.2FabricClient-sideТолько клиент
DownloadСкачать GitHub

The mod only reads chat messages. It never buys, sells or clicks for you. It was made with the help of AI (Claude).Мод только читает сообщения чата. Он ничего не покупает, не продаёт и не кликает за тебя. Мод создан с помощью ИИ (Claude).

How it worksКак работает мод

01BuyПокупка

The mod sees “You purchased … for N coins!” and remembers the price.Мод видит «You purchased … for N coins!» и запоминает цену покупки.

02SellПродажа

When you collect coins in Manage Auctions, it sees “You collected N coins from selling …” and matches the item name.Когда ты забираешь монеты в Manage Auctions, мод видит «You collected N coins from selling …» и находит покупку по названию.

03ProfitПрибыль

Profit = coins received minus the buy price. The auction tax is already deducted.Прибыль = полученные монеты минус цена покупки. Налог аукциона уже вычтен.

04PanelПанель

Total profit, session, coins per hour, last flip and items still waiting to sell.Общая прибыль, сессия, монеты в час, последний флип и предметы, ждущие продажи.

InstallУстановка

  1. Use Minecraft 26.2 with Fabric and Fabric API.Нужен Minecraft 26.2 с Fabric и Fabric API.
  2. Put the mod .jar into your mods folder.Положи файл мода .jar в папку mods.
  3. Join Hypixel SkyBlock and type /flip in chat. It opens the settings menu: language, colors, background, panel position and data reset.Зайди на Hypixel SkyBlock и напиши /flip. Откроется меню: язык, цвета, фон, положение панели и сброс данных.
  4. Flip as usual. Remember to collect your coins in Manage Auctions: profit is counted at that moment.Флипай как обычно. Не забывай забирать монеты в Manage Auctions: прибыль засчитывается в этот момент.

FAQ

Is it safe to use on Hypixel?Безопасно ли это на Hypixel?

The mod only reads chat and draws a panel; it automates nothing. It is not made or approved by Hypixel, so use it at your own risk and follow Hypixel’s rules.Мод только читает чат и рисует панель, ничего не автоматизирует. Он не создан и не одобрен Hypixel, поэтому пользуйся на свой риск и соблюдай правила Hypixel.

Why is my profit not counting?Почему не считается прибыль?
  • Coins must be collected in Manage Auctions.Монеты нужно забрать в Manage Auctions.
  • Items bought before installing the mod go to “unmatched” and do not change profit.Предметы, купленные до установки мода, попадают в «без пары» и не меняют прибыль.
  • If Hypixel changes its message text, the mod must be updated.Если Hypixel изменит текст сообщений, мод нужно обновить.
Does it support the Bazaar?Поддерживается ли базар?

Not yet. Only the Auction House is tracked.Пока нет. Учитывается только аукцион.

Where is my data stored?Где хранятся данные?

In config/fliptracker.json in your game folder. You can reset it from the /flip menu.В файле config/fliptracker.json в папке игры. Сбросить можно в меню /flip.

The game does not startИгра не запускается

Check that Fabric and Fabric API for 26.2 are installed and that only one copy of the mod is in mods. If it still fails, open an issue on GitHub and attach logs/latest.log.Проверь, что стоят Fabric и Fabric API для 26.2 и в mods лежит только один файл мода. Если не помогло, создай обращение на GitHub и приложи logs/latest.log.
